# KWEPU Phase 4 — Professional NGO Standard

This build adds four evidence-based featured programme pages using KWEPU's own project information and photographs:

- Ubuntu Poultry Farming
- KWEPU Tailoring & Textile Skills Project
- KWEPU Kitchen Garden Initiative
- KWEPU Tree Nursery & Tree Planting Initiative / MAKE RUSINGA GREEN

It also updates the Our Work page, homepage featured-programmes section and sitemap. Existing Google Search Console verification, robots.txt, About and Volunteer pages are retained.

Claims are intentionally separated into current work, verified starting facts and future partnership ambitions. No unverified beneficiary totals, financial outcomes, partner names or registration claims have been added.
