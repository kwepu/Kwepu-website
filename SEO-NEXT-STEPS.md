# KWEPU SEO – Next Steps

This package adds foundational on-page and technical SEO without changing the website design.

## Added
- Search-focused page title and meta description
- Canonical URL and crawler directives
- Open Graph and Twitter social-sharing metadata
- NGO structured data (JSON-LD)
- Favicon reference
- robots.txt
- sitemap.xml

## After publishing to GitHub Pages
1. Open Google Search Console and add `https://kwepu.github.io/Kwepu-website/` as a URL-prefix property.
2. Complete Google's ownership verification if requested.
3. Submit `sitemap.xml` in Search Console.
4. Use URL Inspection for the homepage and request indexing.
5. Check indexing and search queries over the following weeks.

## Recommended next phase
- Replace generic gallery alt text with accurate descriptions after identifying what each photo shows.
- Consider dedicated About, Projects, Volunteer, Impact and Contact pages as the site grows.
- Move to a custom KWEPU domain when ready; update canonical, sitemap and structured-data URLs at that time.
